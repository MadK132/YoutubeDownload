# Pocket Video

Приложение для iPhone на Expo SDK 58, React Native и TypeScript. Получает публичные видео YouTube/VK и прямые MP4/MOV непосредственно на устройстве. Для скачивания не нужны включённый ПК, локальный сервис, облачный посредник, платный API или аккаунт приложения.

## Как пользоваться без компьютера

Установите самостоятельную Release-сборку IPA с модулем `PocketMedia`. После установки приложение работает через интернет iPhone, в том числе через мобильную сеть, без подключения к Metro или компьютеру.

1. Вставьте ссылку YouTube, VK Видео или прямую MP4/MOV.
2. Нажмите «Открыть видео», включите плеер и проверьте название ролика.
3. Выберите доступное качество до 1080p и нажмите «Скачать основное видео».
4. Откройте вкладку «Загрузки». Раздельные видео и звук скачиваются последовательно и собираются в MP4 на телефоне. Процент может некоторое время оставаться на 100% во время сборки.
5. Готовый файл доступен без интернета в «Библиотеке»: просмотр, экспорт, сохранение в «Фото», удаление.

Держите приложение открытым во время загрузки и сборки: iOS может приостановить приложение в фоне. После принудительного закрытия незавершённые задачи отмечаются как прерванные; вставьте исходную ссылку заново.

**Важно:** готовый Expo Go не содержит ваш пользовательский Swift-модуль. Для YouTube и сборки раздельных дорожек нужен новый IPA или development build. Веб-версия служит для просмотра интерфейса и плееров; браузер ограничивает чтение сторонних потоков. Это ограничение веб-превью не означает необходимость компьютера при работе установленного приложения. [Документация Expo о development builds](https://docs.expo.dev/develop/development-builds/introduction/).

## Как работает автономная загрузка

- YouTube: библиотека `youtubei.js` получает сведения об исходном ID и доступные незашифрованные MP4/H.264 и AAC-дорожки. Параметры плеера обрабатываются в изолированном JavaScriptCore на iPhone. Видео с DRM и закрытые ролики не поддерживаются. [Поддержка платформ YouTube.js](https://github.com/LuanRT/YouTube.js).
- VK: приложение напрямую запрашивает публичные параметры плеера, сверяет owner/video ID и выбирает MP4 нужного качества. Кириллица Windows-1251 декодируется на устройстве. Структура соответствует публичному плееру VK; код обработки находится в `src/services/providers/vk.ts`.
- Загрузчик использует нативный FileSystem iOS, проверяет HTTP-ответ и заголовок контейнера, отклоняет HTML вместо видео. Готовые файлы находятся в приватной папке приложения.
- Если видео и звук раздельные, `PocketMedia` объединяет локальные файлы через AVFoundation без повышения разрешения и без FFmpeg. [AVMutableComposition](https://developer.apple.com/documentation/avfoundation/avmutablecomposition).
- История хранится в SQLite. Временные URL дорожек остаются в памяти; в историю записывается исходная ссылка без query/fragment. После завершения промежуточные дорожки удаляются.
- Качества показываются только из ответа источника. Для прямого файла доступно Original. Если у ролика доступны лишь 144p/240p, приложение не обещает 1080p.

Доступность публичных потоков зависит от сети телефона и изменений площадок. Скачивайте только контент, на сохранение которого у вас есть разрешение. Прямые эфиры, плейлисты, авторизация, DRM, HLS/DASH для произвольных сайтов не реализованы.

## Защита от скачивания рекламы

Для YouTube/VK используется исходный ID ссылки, а не первый сетевой запрос плеера. Рекламные конфигурации плеера не выбираются в качестве файла. При несовпадении ID, явной метке рекламы или DRM загрузка отклоняется. В нативном плеере при распознанном рекламном состоянии кнопка скачивания временно недоступна.

Для прямых ссылок проверяются известные рекламные домены с границами имён, отдельные сегменты пути и явные рекламные параметры. `adventure.mp4`, короткая длительность и маленький размер не являются самостоятельными признаками рекламы. Проверяются конечный адрес HEAD, тип ответа и метки рекламы при загрузке.

Произвольный рекламный MP4 без метаданных нельзя гарантированно распознать. Системный загрузчик самостоятельно следует перенаправлениям; фильтрация каждого промежуточного перехода не гарантируется. Вшитые рекламные интеграции не вырезаются. Плеер сайта может показывать собственную рекламу — её универсальное обнаружение не обещается.

## Разработка на Windows

Установите [Node.js 24 LTS](https://nodejs.org/en/download), откройте PowerShell в папке проекта:

```powershell
npm ci
npm start
```

`npm start` запускает Metro для собственного development build с нативным модулем. Для интерфейса и прямых файлов можно использовать `npm run start:go` и Expo Go, но он не проверяет автономную загрузку YouTube и сборку дорожек. Веб-превью: `npm run web`. В браузере прямые MP4/MOV требуют CORS на сервере, скачиваются в «Загрузки», а библиотека существует до перезагрузки вкладки.

Разработка с Metro требует соединения с ПК; **Release-сборка IPA содержит JavaScript внутри приложения и этого соединения не требует**.

## Самостоятельный IPA и установка с Windows

Windows не компилирует iOS-приложения локально: для сборки нужен macOS/Xcode. Подготовлен ручной workflow `.github/workflows/ios-unsigned.yml`. Он проверяет TypeScript, тесты и подключение локального модуля, создаёт нативный проект, устанавливает Pods, компилирует Release и упаковывает неподписанный IPA. Пользовательский модуль автоматически обнаруживается Expo в `modules/pocket-media`; см. [автолинковку Expo](https://docs.expo.dev/modules/autolinking/).

1. Разместите исходники, `modules/`, `package-lock.json` и workflow в своём GitHub-репозитории. Не загружайте `node_modules`, личные видео, ключи и временные файлы.
2. В GitHub откройте **Actions → Build unsigned iOS IPA → Run workflow**.
3. После успешной сборки скачайте артефакт `PocketVideo-unsigned`, распакуйте ZIP и получите `PocketVideo-unsigned.ipa`.
4. Подпишите и установите IPA на свой iPhone через AltStore Classic/AltServer по [официальной инструкции для Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows). Неподписанный IPA сам по себе не устанавливается.
5. С бесплатной персональной подписью требуется периодическое обновление подписи, обычно каждые семь дней, и действуют лимиты приложений. См. [ограничения AltStore](https://faq.altstore.io/altstore-classic/your-altstore). Это обслуживание установки; сервис на ПК для скачивания видео больше не используется.

Стандартные GitHub runners публичных репозиториев доступны бесплатно; у приватных репозиториев действуют квоты аккаунта. Проверьте их перед запуском: [правила GitHub Actions](https://docs.github.com/en/billing/concepts/product-billing/github-actions). Workflow подготовлен локально, но здесь не запускался: исходники не публиковались и учётные записи Apple/GitHub не подключались.

Альтернатива при уже имеющемся Apple Developer Program — EAS Build:

```powershell
npx eas-cli login
npx eas-cli build:configure
npx eas-cli build --platform ios --profile preview
```

Перед сборкой замените bundle identifier в `app.json` своим уникальным идентификатором. Обычная ad hoc-сборка EAS для физического iPhone требует платной программы Apple и не является обязательной бесплатной схемой: [документация Expo](https://docs.expo.dev/build/internal-distribution/). Для development build используйте профиль development и `npm start`. Release-профиль preview собирает самостоятельное приложение.

## Проверки и их границы

```powershell
npm run typecheck
npm test
npx expo install --check
npx expo export --platform web
npx expo export --platform ios --output-dir dist-ios
npx expo-modules-autolinking resolve --platform apple --json
```

Диагностика того же алгоритма получения потоков на машине разработчика, без сервера или yt-dlp:

```powershell
npm run device:probe -- https://www.youtube.com/watch?v=jNQXAC9IVRw
npm run device:probe -- https://vkvideo.ru/video-56169357_456267154
```

Диагностика использует Node только как среду запуска общего TypeScript-кода; приложение получает потоки своим кодом на iPhone. Нативный JavaScriptCore в этой диагностике заменён изолированным Node VM. Флаг `--download-small` позволяет полностью проверить дорожки публичного ролика длительностью до минуты.

Реально проверено новым алгоритмом без сервера: YouTube вернул видео MP4 195 278 байт и аудио MP4 309 288 байт; обе дорожки получены полностью с HTTP 200. По пользовательской ссылке VK получены качества 144–1080p и первые байты MP4 с HTTP 206. Полный 47-минутный ролик VK не скачивался. Экспорт iOS/Hermes проходит, Expo обнаруживает PocketMedia для автолинковки.

**Нативная компиляция Swift и сборка/воспроизведение MP4 на физическом iPhone здесь не проверены:** в окружении Windows нет Xcode и iOS SDK. Экспорт JavaScript не заменяет эти проверки. Перед использованием установите новую сборку и проверьте:

1. При выключенном ПК или отключённой Wi-Fi сети телефона публичные YouTube/VK скачиваются через мобильный интернет, готовый файл воспроизводится со звуком.
2. Отмена во время видео, аудио и сборки не добавляет готовый файл в библиотеку; незавершённые дорожки очищаются после перезапуска.
3. Повтор, очередь, импорт из «Файлов», экспорт, разрешения «Фото», удаление и темы работают.
4. Реклама и подмена ID отклоняются; обычный короткий ролик не блокируется только из-за длительности.

## Структура

```text
src/app/                  Вкладки и плеер
src/components/           Общие элементы интерфейса
src/services/providers/   Прямые файлы, YouTube.js, VK и фильтр рекламы
src/services/download/    Очередь, загрузка дорожек и сборка на iPhone
src/services/storage/     Импорт, экспорт и Фото
src/database/             SQLite и адаптер веб-превью
modules/pocket-media/     Swift: JavaScriptCore и AVFoundation
scripts/device-probe.ts   Диагностика общего алгоритма без сервера
```

Прежний сервис на ПК остановлен, его исходники, команды запуска и интерфейс подключения удалены. Старые тестовые файлы в игнорируемой папке `.companion` не используются приложением и могут быть удалены отдельно.
